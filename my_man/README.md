# Установка

Чтобы использовать файловый менеджер как полноценную системную утилиту (вызывать командой `filemanager` из любого места), выполните следующие шаги:

1. **Клонируйте этот репозиторий:**
  
   ```bash
   git clone [https://github.com/Mnameissuha/uni_practicum_tasks.git](https://github.com/Mnameissuha/uni_practicum_tasks.git)
   cd uni_practicum_tasks/my_man

2. **Установите проект в режиме редактирования:**
    pip install -e .
